# Alianza Leadership Program — Site

A simple, one-page informational website for [Alianza for Opportunity](https://www.alianzaforopportunity.org), built to introduce prospective applicants (ages 18–25) to their Alianza Leadership Program — what it teaches, what participants gain, and what opportunities follow completion.

## Purpose

This is my First Controlled Build for the **Next Chapter — Fall 2026** cohort: a small, focused build using only HTML, CSS, and JavaScript, meant to demonstrate clean structure, accessibility, and working from a real organization's actual brand and program materials rather than placeholder content.

The build was led and directed by me. Each step was prompt-driven and documented in [PROMPTS.md](PROMPTS.md), which logs the full process — what was asked for and what was built in response — for instructor review.

## Constraints

The site was built under a specific, deliberate set of constraints:

- **Plain HTML/CSS/JS only** — no frameworks or build tools.
- **Exactly three main content sections** (What You'll Learn, What You'll Gain, Opportunities After Completion) plus one call-to-action — no additional sections.
- **No invented content** — every claim, color, font, and program detail came from Alianza for Opportunity's own brand guidelines and official program flyer. Anything not verified was flagged rather than guessed at.
- **No extra features** — no testimonials, statistics, FAQs, contact forms, newsletter sign-ups, or navigation menus.
- **Accessibility first** — semantic HTML, correct heading order, descriptive alt text, sufficient color contrast, visible keyboard focus, and full responsiveness down to phone width.
- **Brand fidelity** — colors and layout decisions were checked against the organization's real brand guidelines (including contrast testing) rather than chosen arbitrarily.
